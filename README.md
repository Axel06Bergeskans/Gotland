# Swedish Information Website

This project is a simple multi-page website built with **HTML** and **CSS**.  
It provides information about contact details, practical advice, and local attractions.

## 📁 Project Structure

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension (if not already installed).
4. Right-click on `index.html` and select **"Open with Live Server"**.
5. The website will automatically open in your browser.

## 💡 Tips

- Edit `app.css` to customize colors, fonts, and layout.
- Add new images to the `images` folder and reference them in your HTML files.
- To publish the site online, you can use **GitHub Pages** or **Netlify**.
